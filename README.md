# LATEX Resume Template


This is a template for a basic resume in Latex. This has been created for a technical resume for job applications in Germany. Its a simple editable, Latex template that you can easily beautify with your own ideas or using ChatGPT's suggestions. The template uses a free to use google font called "Mulish". This font library has also been included in the Git Repo. You might have to install the font the first time you run it, however as far as I know it is not necessary. But if you run into error's maybe this is something worth checking. 

The main.tex is the heart of your resume. It has all the calls for the other subsections like education, skills etc. If you add a new page or a new section don't forget to include it here, else it wont show up in your latex pdf. The rest of the things are simple, you can customise the settings.json and change the custon file output name too. Currently a new folder called Application->Generic will be created and the pdf will be created there. When you build the Resume and the Cover letter. To get the pdf you have to build the project at least once! 

But this is all the main info. Have fun using this template and Good luck!
